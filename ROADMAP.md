# Proposed development backlog

These are candidate tasks based on the current repository, for the project owner to confirm and prioritize. Estimates are provisional, not a certification of planned work.

- **Reproducible setup (6–8 hours):** verify a fresh installation, complete service configuration examples, and replace the Docker Compose scaffold with a working development stack.
- **Document pipeline reliability (8–12 hours):** exercise OCR and extraction with synthetic documents, test failure and retry behavior, and document supported formats and language handling.
- **Automated validation (6–8 hours):** run and repair the existing backend and frontend tests, document test database setup, and add CI checks with secret scanning.
- **Release preparation (4–6 hours):** review authentication and deployment settings, audit dependencies and licenses, and document backup and upgrade procedures.

The initial publication contains existing implementation and tests; the full application has not yet been validated in a fresh environment.
